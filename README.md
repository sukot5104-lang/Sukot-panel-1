🚀 SUKOT CONFIG — پنل KV Cloudflare

پنل مدیریت کانفیگ SUKOT CONFIG با استفاده از Cloudflare Workers و KV، برای راه‌اندازی و مدیریت پنل به‌صورت آنلاین.

⚙️ راه‌اندازی پنل

وارد داشبورد Cloudflare شوید.

یک فضای ذخیره سازی KV با نام دقیق زیر ایجاد کنید:

"cf-config-panel-kv"

وارد بخش Workers & Pages شوید و یک Worker ایجاد کنید.

کد فایل "Worker.js" را در قسمت ویرایش کد قرار دهید و تغییرات را ذخیره کنید.

در صورت نیاز، KV را از بخش Bindings به Worker متصل کرده و نامگذاری آن را مطابق کد تنظیم کنید.

Worker را Deploy کنید و از طریق لینک اختصاصی آن وارد پنل شوید.
